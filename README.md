# NebulasMotionBlur
A customizable cursor motion-blur overlay for osu! stable on Windows

## How to use

1. Download and extract `NebulasMotionBlur-preview-win-x64.zip`.
2. Open `NebulasMotionBlur.exe`.
3. Select your osu! skin folder in the **Cursor** tab.
4. Choose a preset and open osu!.

RUN IN BORDERLESS OR WINDOWED MODE TO WORK.

Requires [Windows x64 .NET Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

Experimental visual effect only. It does not increase your monitor’s refresh rate or modify osu! gameplay.
